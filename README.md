\# Calculator Project



A Django-based calculator web application using HTML, CSS, Bootstrap, and Python Django.



\## Features

\- Responsive UI

\- Arithmetic calculations

\- Django backend

\- Bootstrap frontend



\## Technologies Used

\- HTML

\- CSS

\- Bootstrap

\- Python

\- Django



\## Installation



\### Clone Repository



```bash

git clone https://github.com/YOUR\_USERNAME/calculator\_project.git

```



\### Move Into Project Folder



```bash

cd calculator\_project

```



\### Create Virtual Environment



```bash

python -m venv venv

```



\### Activate Virtual Environment



\#### Windows



```bash

venv\\Scripts\\activate

```



\### Install Dependencies



```bash

pip install -r requirements.txt

```



\### Run Server



```bash

python manage.py runserver

```
